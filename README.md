# INMOTECH

Todo el negocio inmobiliario, en una sola pantalla.

Prototipo navegable de la primera entrega. Datos ficticios, sin backend.

- `index.html`: archivo autocontenido (funciona offline y en GitHub Pages).
- Pantallas: ingreso, Inicio (dashboard ejecutivo), Propiedades, Ficha de propiedad, Contratos, Cobros con registro de pago parcial multimoneda, Gastos, Caja y bancos, Finanzas, Centro de vencimientos, Configuración (organización, usuarios y permisos, monedas, categorías) y Sistema visual.
- Pendiente de implementación: servidor, autenticación real, integraciones (Mercado Pago, bancos, facturación, WhatsApp), almacenamiento documental e importación desde Excel.
